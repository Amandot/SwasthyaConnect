DEPLOYMENT STEPS
═══════════════════════════════════════════════════════════════

Frontend (Vercel):
□ Install Vercel CLI: npm install -g vercel
□ Build: cd frontend && npm run build:prod
□ Deploy: vercel --prod
□ Add environment variables in Vercel dashboard
□ Configure custom domain
□ Enable HTTPS redirect
□ Test deployment: https://your-domain.com

Backend (Railway):
□ Create Railway account
□ Connect GitHub repository
□ Set root directory: telehealth-system/server
□ Add environment variables:
  □ PORT=5000
  □ NODE_ENV=production
  □ FRONTEND_URL=https://your-frontend-domain.com
  □ GEMINI_API_KEY=your_key
□ Upload Firebase service account JSON
□ Deploy and get backend URL
□ Update VITE_API_URL in frontend with backend URL
□ Redeploy frontend with updated API URL

Alternative - Docker:
□ Build images: docker-compose build
□ Test locally: docker-compose up
□ Push to registry: docker push
□ Deploy to server
□ Configure reverse proxy (nginx)
□ Set up SSL with Let's Encrypt
