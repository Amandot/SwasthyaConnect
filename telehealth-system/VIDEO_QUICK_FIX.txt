COMMON FIXES:

❌ "Camera/Microphone Blocked"
   → Click camera icon in browser address bar
   → Select "Always allow"
   → Refresh page

❌ "Can't see other person"
   → Both users MUST use SAME room ID
   → Example: both use /consultation/room123

❌ "Stuck on connecting"
   → Check internet connection
   → Disable VPN
   → Try different browser (Chrome recommended)

❌ "No video preview"
   → Close other apps using camera (Zoom, Teams, etc.)
   → Try incognito mode
   → Restart browser
